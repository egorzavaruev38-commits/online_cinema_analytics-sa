# Границы аналитической системы онлайн-кинотеатра


## Назначение 

Аналитическая система формирует отчёты об интересе зрителей к фильмам и жанрам, чтобы контент-менеджер и продуктовый аналитик принимали решения на основе данных.

## Входит в MVP

1. Получение событий просмотров, каталога фильмов и оценок из онлайн-кинотеатра 
2. Расчет метрик: средний рейтинг, доли завершённых просмотров, средняя длительность просмотра, число оценок.
3. Составление отчета
4. Отображение отчета с визуализациями

## Не входит в MVP

1. Регистрация пользователей 
2. Приём платежей 
3. Сбор оценок зрителей
4. Воспроизведение фильмов

## Взаимодействия на границе

- Онлайн-кинотеатр передает события просмотров, каталог фильмов и оценок.
- Аналитическая система предоставляет отчёт контент-менеджеру и продуктовому аналитику.
