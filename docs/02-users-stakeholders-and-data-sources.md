# Пользователи, Стейкхолдеры и источники данных

## Пользователи системы

Контент-менеджер использует отчёт, чтобы принимать решения о продвижении фильмов и жанров.
Продуктовый аналитик анализирует отчёт, выявляет интересы зрителей и закономерности.


## Стейкхолдеры

- Руководитель продукта — принимает решения о развитии онлайн-кинотеатра и определяет требования к отчёту.

## Источники данных

- Событие просмотра: id просмотра, id зрителя, id фильма, время начала и окончания просмотра, тип устройства.
- Каталог фильмов: id фильма, название, жанр, длительность фильма.
- Оценка: id фильма, id пользователя, рейтинг, дата оценки.

## Роль зрителя

Зритель — пользователь онлайн-кинотеатра, но не пользователь аналитической системы. Его действия в онлайн-кинотеатре создают события для анализа.
